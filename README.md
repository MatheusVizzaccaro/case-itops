# case-itops
Case ITOps - Sistemas Operacionais em Nuvem

Descrição do case:
Uma empresa, possui múltiplas antenas (Access Points) ligadas a um Switch, e esse switch envia os dados para um Firewall, para encaminhamento dos dados via rede. Portanto, nessa empresa, é comum que o gerenciamento das redes é uma incógnita e algo difícil de se mensurar. Portanto, nesse repositório, é proposto uma possível solução desse case, que gera um relatório de razão entre uso do hardware do Switch e a quantia de dados enviados e recebidos.
